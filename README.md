# Escuta DF - Ouvidoria Digital Inteligente

Projeto criado para o Hackathon Code for GovTech (Brasília/DF), com o objetivo de tornar a participação cidadã no governo tão simples quanto enviar um áudio no WhatsApp. O Escuta DF elimina barreiras de escrita e acessibilidade, permitindo que qualquer pessoa registre denúncias, sugestões ou elogios de forma rápida, inclusiva e segura.

## 🚀 Principais Funcionalidades
- **Acessibilidade Total:** Interface com alto contraste, navegação por teclado, compatível com leitores de tela e widget VLibras para Libras.
- **Multicanal de Entrada:** Aceita Texto, Áudio (com transcrição automática), Vídeo em Libras e Imagens com geolocalização.
- **Anonimato Garantido:** O cidadão pode optar por não se identificar, protegendo sua privacidade.
- **Geolocalização Inteligente:** Captura automática de latitude/longitude para facilitar a gestão pública e gerar mapas de calor das demandas.
- **PWA:** Funciona como aplicativo no celular, sem necessidade de download.

## 🛠️ Tecnologias Utilizadas
- **Frontend:** React, Vite, TailwindCSS, Shadcn UI.
- **Backend:** Node.js, Express.
- **Banco de Dados:** PostgreSQL (Supabase) ou LocalStorage (modo demo).
- **ORM:** Drizzle.

## 💻 Como Rodar Localmente
1. Clone este repositório.
2. Instale as dependências:
   ```bash
   npm install
   ```
3. (Opcional) Configure o arquivo `.env` com suas credenciais do Supabase.
4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
5. Acesse [http://localhost:5000](http://localhost:5000) no seu navegador.
